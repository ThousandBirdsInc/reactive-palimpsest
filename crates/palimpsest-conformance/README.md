# palimpsest-conformance

Real-Postgres conformance harness for Palimpsest (§18.13).

This crate is **nightly-only and opt-in**. The default build is empty
so the main workspace `cargo build` / `cargo test` does not require a
running Postgres. Conformance work is gated behind:

- the `real-postgres` cargo feature, and
- the `PALIMPSEST_PG_URL` environment variable.

```bash
# Local dry-run (no DB needed; tests print "skipped"):
cargo test -p palimpsest-conformance --features real-postgres

# Against a running Postgres:
PALIMPSEST_PG_URL=postgres://palimpsest:palimpsest@localhost:5432/palimpsest \
    cargo test -p palimpsest-conformance --features real-postgres
```

## Layout

| Path | What it covers |
| --- | --- |
| `tests/wire_bytes.rs` | §18.13.3 — `WalGenerator::encode_pgoutput` vs real-PG pgoutput |
| `tests/catalog_responses.rs` | §18.13.4 — fixed catalog SELECTs vs `fixtures/*.json` |
| `tests/oracle.rs` | §18.13.5 — property-test corpus vs `ReferenceExecutor` |
| `tests/replication_smoke.rs` | §18.13.6 — §15.6 scenarios end-to-end |
| `fixtures/*.json` | Canonical catalog responses (regenerated by xtask) |
| `corpus/*.sql` | Human-readable view of the oracle corpus |

## Regenerating fixtures

```bash
PALIMPSEST_PG_URL=... cargo run -p xtask -- regen-pg-fixtures
```

Commit the fixture diff alongside the code change that motivated it.

## Postgres version matrix

The nightly `conformance.yml` workflow runs every test against:

- Postgres 16
- Postgres 17

Failures auto-file a P1 issue; nightly failures **never block PRs**.
