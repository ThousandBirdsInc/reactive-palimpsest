06Row-level permissions

Rules compile into the plan.

# permissions.toml [[rule]] name = "own_tickets" table = "tickets" predicate = "owner_id = $user.id"
Project(id, title)
Filter owner_id = $user.id
Scan tickets
Rules are validated against the catalog at load time and spliced into each subscription as MIR filters. Rows are filtered before they leave the server — and revoked access arrives as a retraction.
